# 优优成长相册

一款记录宝宝成长的手机 App。所有数据只存在手机本地，不联网、不上传，保护隐私。

## 已经做好的功能（V1）

- **宝宝档案**：填名字和出生日期，自动算出"X岁X个月X天"、已出生多少天、第几个月。
- **相册导入**：读取手机相册，把照片按拍摄时间自动归到"第几个月"，形成成长时光轴。
- **AI 筛选照片**：圈几张宝宝正脸当样本，App 自动从相册里挑出相似照片（本地运行，不上传，结果需人工核对）。
- **成长记录**：写日记，发布后自动带上日期、星期、宝宝第几天，可以配图。
- **新技能**：记录宝宝新学会的技能和时间，时间线展示。

后续版本（V2）计划：身高体重成长曲线、一键生成成长视频、家人共享、云备份。

## 怎么拿到能装到手机的安装包

你选的是**云端打包**：让 GitHub 的免费服务器帮你编译出安卓安装包（APK），你不用在自己电脑装复杂环境。一共 5 步，照做即可。

### 第 1 步：注册一个 GitHub 账号（免费）

打开 https://github.com → 右上角 Sign up → 用邮箱注册，一路下一步。

### 第 2 步：下载并安装 GitHub 桌面版

打开 https://desktop.github.com → 下载 Windows 版 → 一路默认安装 → 用第 1 步的账号登录。
（这个软件的作用是：把项目文件传上 GitHub，不需要你懂命令行。）

### 第 3 步：把项目上传到 GitHub

1. 打开 GitHub 桌面版，点左上角 `+` → `Add`（添加）→ `Clone`（克隆）… 这一步先跳过，我们改用另一种更简单的：
2. 打开网页 https://github.com → 右上角 `+` → `New repository`（新建仓库）。
3. 仓库名随便填，比如 `youyou-album`，其他都不用改，点 `Create repository`。
4. 创建好后，页面上有 `uploading an existing file`（上传已有文件）的链接，点它。
5. 把本文件夹（`youyou_growth_album`）里的**全部文件和文件夹**拖拽到那个上传区域（包含 `.github` 这个隐藏文件夹——在 Windows 里先开启"显示隐藏的项目"才能看到它，或者干脆用下面的"命令行方式"）。
6. 点 `Commit changes` 提交。

> **更稳妥的办法（推荐）**：用 GitHub 桌面版
> - 在电脑上新建一个空文件夹，比如 `D:\youyou-album`。
> - 把本项目的所有内容复制进去（包括 `.github` 文件夹）。
> - 打开 GitHub 桌面版 → `+` → `Add` → `Add an Existing Repository from your Hard Drive`（从本地添加已有仓库）→ 选择刚才那个文件夹 → 再选第 3 步建好的空仓库 → 点 `Clone/添加`。
> - 在软件左侧勾选所有改动，底部写一句话比如"首次上传"，点 `Commit to main`，再点右上角 `Push origin`（推送）。

### 第 4 步：等云端自动打包

1. 上传成功后，打开你的仓库网页，点顶部 `Actions` 标签页。
2. 左侧点 `打包安卓 APK`，右侧会看到一次正在运行的任务（黄点）或已完成（绿勾）。
3. 点进那次任务，等它跑完（一般 3~8 分钟）。如果显示绿色对勾，说明成功了。

### 第 5 步：下载 APK 装到手机

1. 在成功那次任务的页面往下拉，找到 `Artifacts`（产物）区域，点 `youyou-apk` 下载，得到一个 zip 压缩包。
2. 解压后是一个 `.apk` 文件。
3. 把 APK 传到你的安卓手机（微信发给自己、数据线拷贝、或手机浏览器登录邮箱下载都行）。
4. 在手机上点这个 APK 安装。第一次会提示"不允许安装未知来源应用"，按提示去设置里允许一下即可。
5. 装好后打开 App，填宝宝名字和出生日期就能用了。

> 苹果手机装不了 APK。苹果需要打包 IPA，必须有苹果开发者账号（每年付费）或用 TestFlight，云端免费环境做不了。如果你用苹果手机，我可以另外给你一份"用 Mac 电脑自己打包 IPA"的教程。

## 常见问题

**Q：Actions 任务显示红叉（失败）怎么办？**
把页面往下拉，看红色报错的最后几行，截图发给我，我帮你改。

**Q：AI 识别不准 / 认不出？**
- 先确认圈了 3~5 张清晰正脸当样本。
- 在"AI 自动筛选"里把相似度阈值调低一点（比如 0.6），会更容易认出但可能多选；调高则更严格。
- 光线暗、侧脸、戴帽子、相隔一岁以上的照片容易认错，这是本地轻量识别的普遍限制，导入后请人工核对。

**Q：照片会不会上传到网上？**
不会。所有照片、样本指纹、记录都存在你手机本地，App 没有联网上传功能。

**Q：换手机数据会丢吗？**
V1 数据只在本机。换手机需要手动备份相册照片。V2 会加云备份功能。

## 给开发者的技术说明

- 技术栈：Flutter 3 + Dart 3，一套代码可打 Android / iOS。
- 本地数据库：sqflite；相册：photo_manager；人脸检测：Google ML Kit（端上离线）；状态管理：provider。
- 项目结构：`lib/models`（数据模型）、`lib/services`（数据库/相册/人脸/日期服务）、`lib/providers`（全局状态）、`lib/screens`（页面）、`lib/widgets`（通用组件）。
- 云端打包：`.github/workflows/build-apk.yml`，push 到 main/master 自动触发，产物保留 90 天。
- 人脸方案是"灰度指纹 + 关键点"的轻量实现，不是深度学习人脸向量模型；如需工业级准确率，替换 `lib/services/face_recognition_service.dart` 为 TFLite 人脸特征模型即可。
